# 蓝毛小女仆 v0.3.0

在 v0.2.0 上增加可选的 Claude 皮肤。默认仍是蓝毛小女仆，原有 106 段动画和活动都保留。v0.2.0 的 Release 和安装包不替换。

- 菜单可以在蓝毛小女仆和 Claude 之间切换，选择会记住。
- Claude 活动列表只显示已实现的 25 个动作；切回蓝毛小女仆时恢复她的完整活动。
- 支持文档、图片、音视频、表格、PPT、文本、电子书、字幕和 ZIP 图片转换，与 v0.2.0 相同。
- 提供 macOS Apple Silicon 的 DMG/ZIP，以及 Windows 10/11 x64 的 EXE 安装包，附 SHA256SUMS.txt。
- 不提供 Linux 安装包。

Claude 的 25 段是模仿原动作风格的新动画，不是逐帧复刻。整理纸张中段的纸张会由小片变成较大的板。抬腿踢出的画面里没有毽子。放风筝为了让风筝完整留在画面里，角色比其他片段略小。胸口「Claude」在大幅动作里可能变形或被挡住，窗口里显示也很小。

本版没有开发者签名证书；Mac 使用临时签名，未公证；Windows 未进行发布者签名。详细安装步骤与工具来源见 [安装说明](https://github.com/yukino0637-stack/blue-maid-converter/blob/v0.3.0/docs/INSTALL.md)。

人物动画中的蓝毛小女仆来自 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)，保留非商用与署名要求。Claude 皮肤的原始角色图按收到的文件原样保存，25 段视频是生成后再抠成透明通道的版本。格式规则参考 [FlyingMouse Format](https://github.com/LaoFeng-mouse/flyingmouse-format)。公开版不分发缺少授权的小黄鸭音频，请通过菜单导入自有或有适用授权的 MP3/WAV。
