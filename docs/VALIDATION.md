## 既有本机行为检查

此前开发记录检查过：待机与工作真实循环、结束动画真实 ended 后回待机、中文失败、文件与目标保护、透明比例及置顶、菜单悬停与响应矩形、105 个活动、六个随机点击回应、真实一分钟待机计时、拖拽与松手落地。这些是之前版本的本机证据，本次发布保留相同运行代码；不能据此声称所有机器或所有输入均通过。

涉及默认小黄鸭音效的历史界面检查使用本机开发素材，**不构成再分发授权**。公开版 `test:ui` 和 `test:menu` 需要自行准备有权使用的 MP3，放在被 Git 忽略的 `assets/duck-sound/Ya1.mp3`；也可只运行不依赖默认音频的基础与格式检查。

Command+D 的真实实体按键在此前由维护者确认可用，后台检查曾确认注册和启动记录；本次没有再次改装日常启动器，也没有重新登录验证登录启动。公开仓库提供源码和安装说明，其他使用者需自行安装。

## 尚未覆盖

- Windows/Linux、Intel Mac、其他 Node.js 版本与独立签名安装包。
- 每种实际文件的复杂排版、字体、特殊编码、损坏或加密变体；PDF→Word 仍为实验功能，扫描件无 OCR。
- 发布副本的 Finder 原生拖拽和系统选择/保存对话框；界面自动检查使用真实磁盘文件触发 drop，并替代对话框。
- 扬声器实际听感；音效检查观察浏览器真实解码、时间推进与 ended。

测试只证明上述路径与样例。查看和核对自己的转换结果，尤其是 PDF→Word、CSV/TSV 与复杂 Office 文件。
