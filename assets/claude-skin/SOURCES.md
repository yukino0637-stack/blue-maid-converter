# Claude 皮肤

可选皮肤。默认仍是蓝毛小女仆，原有 106 段 WebM 和活动行为保持不变。

`claude-character.png` 是收到的原始角色图，字节未改。SHA-256：`c1e376c5fd17281ba57f894a2829f893213d16b6f963fe5d181d8ea1281b262c`。参考图只定义外观：蓝发、白橙衣服、蓝尾巴、胸口工牌「Claude」。它不是固定的抬臂姿势。

同目录 25 段 WebM 是按原仓库动作风格做的模仿，不是逐帧复刻。规格为 640×360、24fps、无声、VP9 透明通道。播放仍按窗口里的 256×144 显示。

## 已知限制

- 动作是模仿，不保证与女仆原片逐帧一致。
- `sort.webm` 中段纸张会由小片变成较大的板，仍予保留。
- `kick.webm` 是抬腿踢出，画面里没有毽子，菜单名不用「踢毽子」。
- `kite.webm` 为了让风筝完整留在画里，角色比其他片段略小。
- 胸口工牌在大幅动作里可能变形或被挡住；窗口里的字也很小，不能把成片说成与原图像素完全一致。
- 视频是生成后再抠成透明通道的版本。原始角色图单独按原字节保存。
